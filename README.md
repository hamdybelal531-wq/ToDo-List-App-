ToDo List App

A simple and interactive ToDo List application built with React and Tailwind CSS.
The app allows users to manage their daily tasks efficiently with an intuitive user interface.

Features

Add, edit, and delete tasks

Mark tasks as completed or pending

Filter tasks by status (All, Completed, Pending)

Persistent data using LocalStorage

Responsive design for desktop and mobile

Clean and minimal user interface

Tech Stack

React – Frontend framework

Tailwind CSS – Styling and responsive design

LocalStorage – Save tasks between sessions
